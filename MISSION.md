# Mission: Become ready to work in Go projects

## Why
Be familiar enough with Go to contribute when an upcoming project uses it. Build on existing JS/TS knowledge through small programs that can be read, run, and changed.

## Success looks like
- Find a program's entry point and run an example independently.
- Read and change ordinary Go code using values, control flow, functions, and collections.
- Recognize common Go patterns for errors, interfaces, tests, and basic concurrency.

## Constraints
- The learner knows JS/TS; depth of experience is not yet established.
- Keep each lesson within about 10 minutes, with brief explanations beside runnable code.
- Use the existing standard-library examples, compatible with Go 1.22.1.

## Out of scope
- Advanced runtime internals, generics, reflection, and performance tuning in the initial course.
- Production services, frameworks, databases, and deployment in the initial course.
