Quick reference & glossary · Topic 01 note

1. Read the shape

Familiar JavaScript call

console.log("Hello, World!");

Go command

package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}

Use the familiar function call as a bridge. In Go, package main identifies the executable package, and func main() declares its entry function. Go initializes the program, then calls that function. Source: program execution.

import "fmt" makes this standard-library package available; fmt.Println calls its printing function. It writes the greeting and adds a newline. Source: Println.

func introduces a function, and the braces contain its body. Here main has no parameters or return value. Source: official starter tutorial.

Expected output:
