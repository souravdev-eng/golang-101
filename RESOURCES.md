# Go Resources

## Knowledge

- [Go tutorial: Get started with Go](https://go.dev/doc/tutorial/getting-started#code)
  Official introduction to a runnable program and the go command. Use the “Write some code” section for lesson 0001; the repository already has a module, so skip recreating it and the external-package exercise.
- [Go specification: Program execution](https://go.dev/ref/spec#Program_execution)
  Authoritative rules for package main, its main function, initialization, and exit. Use for resolving entry-point questions, rather than as beginner reading.
- [fmt documentation: Println](https://pkg.go.dev/fmt#Println)
  Official description of console output, spaces, and newline behavior. Use for predicting printed results.

- [A Tour of Go](https://go.dev/tour/)
  Official interactive tour. Each topic note links the matching Tour page; the primary source for the course.
- [Effective Go](https://go.dev/doc/effective_go) and [Go blog: Slices intro](https://go.dev/blog/slices-intro)
  Official idiom guide and deep-dive posts cited in the topic notes.

## Wisdom (Communities)

- [Go project's help directory](https://go.dev/help)
  Official directory of community help channels. Use when seeking practitioner feedback on a small program; joining a community is optional.
