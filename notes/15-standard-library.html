Everyday standard library

Meet common packages through short programs: clean text, format dates, sort a list, work with paths and flags, copy data, read JSON, handle HTTP, and cancel work.

What this folder is for

Go ships with a large standard library, a set of packages that come with Go itself, so small jobs need no third-party dependencies (Standard library index). The skill to take away is the habit: import the package, then call package.Function.

JS/TS you know

const clean = "  Tea,Milk,Bread  "
  .trim()
  .toLowerCase();
const items = clean.split(",");
items.join(" | ");

Go equivalent

clean := strings.TrimSpace("  Tea,Milk,Bread  ")
clean = strings.ToLower(clean)
items := strings.Split(clean, ",")
strings.Join(items, " | ")

In JS these are methods on the string. In Go they're functions in the strings package that take the string as their first argument and return a new string (strings package).

The helpers in this example

strings.TrimSpace(s)
Returns s with whitespace at the start and end removed.
strings.ToLower(s)
Returns a lower-case copy of s.
strings.Split(s, sep)
Cuts s at each sep and returns a []string, a slice of strings (Topic 07).
strings.Contains(s, sub)
Reports whether sub appears in s, as a bool. The match is case-sensitive.
strings.Join(items, sep)
The reverse of Split: glues a []string together with sep between the items.

What to look for in each example

Run every command from the repository root, the folder that contains go.mod.

01 · Cleaning a shopping list

15-standard-library/01-strings/main.go

  • The grouped import: import ( "fmt" "strings" ) is how Go imports more than one package.
  • clean = strings.ToLower(clean) assigns the result back. The helper returns a new string. It doesn't change the old one in place.
  • The text is lower-cased before Contains(clean, "milk"). That's why the case-sensitive check finds Milk.
  • Println prints a slice in square brackets with spaces between the items: [tea milk bread].

Run

go run ./15-standard-library/01-strings

Expect

has milk: true
display: tea | milk | bread

Try: add ,Eggs to the input string. Predict the display: line before you run it.

02 · Parsing and formatting a date

15-standard-library/02-time/main.go

  • time.Parse(layout, text) reads a date and returns a time.Time and an error. Check the error before using the date.
  • Go's layouts show the reference date Mon Jan 2 15:04:05 MST 2006. The layout 2006-01-02 means year-month-day.
  • Format turns the parsed date back into text. AddDate(0, 0, 7) adds seven calendar days.

Run

go run ./15-standard-library/02-time

Expect

date: Mon, 01 Jan 2024
one week later: 2024-01-08

Try: change the input to 2024-01-02. Predict the weekday and the date one week later.

03 · Sorting a copy of a slice

15-standard-library/03-slices/main.go

  • slices.Clone(prices) copies the slice so the original order stays available.
  • slices.Sort(sorted) changes the copied slice in place. It does not return a sorted slice.
  • slices.Contains(sorted, 9) reports whether the slice includes that value.

Run

go run ./15-standard-library/03-slices

Expect

original: [12 5 9]
sorted: [5 9 12]
has 9: true

Try: add 3 to prices. Predict the new sorted slice.

04 · Working with a file path

15-standard-library/04-filepath/main.go

  • filepath.Join combines path parts with the current operating system's separator.
  • filepath.Dir gets the folder, Base gets the file name, and Ext gets its extension.
  • filepath.ToSlash makes the displayed paths identical across operating systems. These functions handle path text; they do not create a file.

Run

go run ./15-standard-library/04-filepath

Expect

folder: reports/2024
file: sales.csv
extension: .csv

07 · Reading and writing JSON

15-standard-library/07-json/main.go

  • json.Unmarshal reads JSON into a struct; it needs a pointer so it can fill the fields.
  • Struct tags such as json:"name" set the JSON key. json.Marshal converts the struct back to JSON bytes.
  • Both calls can return an error, so the program checks each one.

Run

go run ./15-standard-library/07-json

Expect

product: tea 12
json: {"name":"tea","price":12}

Try: change the price in the JSON input to 15.

15-standard-library/08-http/main.go

  • httptest.NewRequest and NewRecorder let the handler run locally, with no server or internet connection.

Finding the next helper yourself

Or from your terminal: go doc strings.Split prints the docs for a single function.

Gotchas coming from JS/TS

  • There are no string methods: s.trim() doesn't exist. Reach for strings.TrimSpace(s).
  • Go strings can't be changed. Text-transforming helpers return a new string, so remember to use or assign the result.
  • Go's names don't always match JS's. JS trim is TrimSpace in Go; Go's strings.Trim needs a list of characters to cut.
  • Go date layouts use the reference date, not YYYY or MM tokens.
  • slices.Sort changes the slice you pass in. Clone it first when you need the original order.
  • Use path/filepath for file system paths. The separator can differ by operating system.
  • Call flag.Parse() before reading flag values. The flag helpers return pointers.
  • json.Unmarshal needs a pointer to the value it fills.
  • An HTTP handler can be exercised locally with httptest.

Check yourself

Which call returns a []string?

Split cuts one string into a slice of strings. Join goes the other way, and TrimSpace returns a single string.

What does strings.Contains("Tea,Milk", "milk") return?

Contains compares exactly, so "milk" doesn't match "Milk". That's why the example lower-cases the text first.

What does time.Parse return besides a date?

Parsing can fail when the text does not match the layout, so check the error before using the date.

How do you sort a slice while keeping its original order?

slices.Sort changes its input. A clone gives it a separate slice to change.

Which function gets sales.csv from reports/2024/sales.csv?

Base returns the final path element. Dir returns its folder, and Ext returns .csv.

What does flag.Parse() do?

After defining flags, call flag.Parse() so supplied options replace the defaults.

Why does json.Unmarshal receive &product?

The pointer lets Unmarshal update product's fields.

  1. Standard-library packages cover everyday text, dates, slices, paths, flags, I/O, JSON, HTTP, and cancellation.
  2. Check errors from parsing and I/O; clone a slice before sorting if you need its original order.
  3. Look anything up at pkg.go.dev/<package> or with go doc.
