Conditions and switches

This folder shows how Go picks which block of code runs. After this, you can read an if with a setup statement and a switch with no value, both of which are common in real Go code.

What this folder is for

if and switch look almost like JS, but with less punctuation. There are no parentheses around the condition, and braces are always required.

JS/TS you know

if (temp < 15) {
  coat();
} else if (temp < 25) jacket();

switch (day) {
  case "Sat": case "Sun":
    weekend(); break;
}

Go equivalent

if temp < 15 {
    coat()
} else if temp < 25 {
    jacket()
}

switch day {
case "Sat", "Sun":
    weekend() // no break needed
}

A Go switch stops after the matching case. You don't write break (Tour: Switch).

The patterns to recognise

if / else if / else
Checked top to bottom. The first true branch runs and the rest are skipped.
if a && b
A combined condition, using the operators from Topic 03.
if x := f(); x > 0 { }
An if with a short statement. x exists only inside this if and its else (Tour: If with a short statement).
switch value { case … }
Compares one value against each case. A case can list several values.
switch { case cond: }
A switch with no value. The first true case wins, so it works like a neat if/else if chain (Tour: Switch with no condition).
default
Runs when no case matches.

Gotchas coming from JS/TS

  • The condition must be a bool. if name { } doesn't compile when name is a string (Go spec: If statements).
  • Braces are required, even for a one-line body.
  • Cases don't fall through. If you really want that, Go has an explicit fallthrough keyword, but you'll rarely see it (Go spec: Switch statements).
  • A variable declared in if x := …; disappears after the if/else block.

Check yourself

score := 95. In the example's valueless switch, which line prints?

score >= 90 is the first true case, so it runs and the switch ends. There's no fall-through into the next case.

After if remaining := 7; remaining > 0 { … } ends, can you print remaining?

A variable from the short statement exists only inside the if and its else. Outside, the name is undefined.

In short

  1. No parentheses, braces always, and the condition must be a bool.
  2. if x := …; cond keeps a helper variable inside the if.
  3. switch needs no break. A valueless switch is a tidy if/else chain.
