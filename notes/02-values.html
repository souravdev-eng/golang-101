Variables, constants, and types

This folder shows how Go stores a value, changes it, and keeps track of its type. After this, you can read any declaration line and know its type and starting value.

What this folder is for

In JS a variable can hold anything. In Go, every variable has one fixed type, chosen when it is declared. Go often works out the type for you, so the code still looks light.

JS/TS you know

let apples = 3;
const shop = "Corner shop";
apples = 5;
let count; // undefined

Go equivalent

apples := 3
const shop = "Corner shop"
apples = 5
var count int // 0, not undefined

There is no undefined. A variable with no value gets its type's zero value (Tour: Zero values).

The ideas to recognise

var x int = 3
Declares a variable and names its type.
var x = 3
Same, but Go infers the type from the value.
x := 3
Short declaration. It declares and sets a new variable. It works only inside functions (Tour: Short variable declarations).
x = 5
Plain = changes a variable that already exists.
const
A fixed value. You can't assign to it later, and it never uses :=.
zero values
0 for numbers, false for bool, "" for string.
T(x)
Conversion, for example float64(total). Go never converts between number types for you (Tour: Type conversions).

04 · Type conversion

02-values/04-conversion/main.go

  • 7 / 2 with two ints gives 3. The fraction is dropped.
  • Convert both sides with float64(…) to keep the fraction.
  • int(3.5) goes back to 3. It drops the fraction; it doesn't round.

Try: change total to 9 and predict both division results.

Gotchas coming from JS/TS

  • JS has one number type. Go has separate int and float64, and you can't mix them in one expression without converting.
  • := can't be used outside a function. At package level, use var.
  • A local variable you declare but never use is a compile error.
  • Once a variable is an int, you can't put a string in it later.

Check yourself

What does var total float64 hold before anything is assigned?

Every Go type has a zero value. For numbers it is 0. Go has no undefined.

a := 7 and b := 2. What is a / b?

Both are int, so this is integer division and the fraction is dropped. Use float64(a) / float64(b) to get 3.5.

In short

  1. Use := to declare a new variable and = to update one.
  2. Every variable has one type, and it starts at its zero value.
  3. Go never converts between number types on its own. You write float64(x).
