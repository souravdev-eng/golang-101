Structs and methods

This folder shows how Go groups related data into one type, and how it attaches behaviour to that type. It's Go's answer to the objects and classes you use in JS/TS.

What this folder is for

Go has no classes. Instead you declare a struct type (named fields), then declare methods for it as separate functions. Most real Go code is built from these two pieces (Tour: Structs, Tour: Methods).

JS/TS you know

class Rectangle {
  constructor(
    public width: number,
    public height: number,
  ) {}
  area() {
    return this.width * this.height;
  }
}

Go equivalent

type Rectangle struct {
    Width  int
    Height int
}

func (r Rectangle) Area() int {
    return r.Width * r.Height
}

The data and the method are written separately. The method is tied to the type by the receiver, the (r Rectangle) part before the method's name.

Key ideas

type Book struct { … }
Declares a new named type with a fixed list of fields. Each field has a name and a type. You can't add fields at runtime the way you can on a JS object.
Book{Title: "Go Basics", Pages: 80}
A struct literal creates a value. Naming the fields makes it easy to read, and any field you leave out gets its zero value (Tour: Struct literals).
book.Pages
A dot reads or writes a field, just like in JS.
var empty Book
A struct that you declare without a value is not undefined. Every field holds its own zero value: "", 0, false, and so on.
func (r Rectangle) Area() int
A method is a function with a receiver. With a value receiver like this one, the method works on a copy of the struct.
Capital letters
Title and Area start with capitals, so code in other packages can use them. Lowercase names stay private to their package (Tour: Exported names).

Gotchas coming from JS/TS

  • There's no this keyword. The receiver is an ordinary named parameter. By convention it's short, often one or two letters such as r.
  • There are no constructors. A struct literal, or a plain function such as NewBook(…), creates the value.
  • Assigning a struct to another variable copies all of its fields. In JS, two variables would point at the same object. Topic 11 covers how to share one value instead.
  • You can only declare methods on types from the same package. You can't add a method to int or string directly (Tour: Methods continued).

Check yourself

You declare var b Book and don't assign anything. What does b.Pages hold?

Each field starts at its type's zero value. For int that's 0. Go has no undefined, and an int can never be nil.

In func (r Rectangle) Area() int, what is (r Rectangle)?

The part before the name is the receiver. It attaches Area to Rectangle and gives you r to use inside, the way you'd use this. The result type, int, comes after the parentheses.

In short

  1. A struct is a named type with fixed fields. Fields you don't set start at zero values.
  2. A method is a function with a receiver. It's declared outside the struct.
  3. With a value receiver, the method gets a copy of the struct.
