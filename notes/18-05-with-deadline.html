Cancelling at a fixed moment with WithDeadline

Almost identical to WithTimeout — one difference. A timeout is a duration ("20ms from now"). A deadline is an instant ("at exactly this clock time").

The idea

Use a deadline when the stop moment is fixed no matter when this code starts — "every request must finish by 12:00:00", or "stop when the parent's deadline arrives". You build the instant with time.Now().Add(...) (or any time.Time), and everything else is the same shape: a cancel function, defer cancel(), and a select on ctx.Done().

WithTimeout(ctx, 20*time.Millisecond)
"Give up 20ms after this line runs."
WithDeadline(ctx, someMoment)
"Give up when the clock reaches someMoment." Internally, timeout is just deadline = now + duration.

The code that matters

deadline := time.Now().Add(20 * time.Millisecond) // a MOMENT, not a length
ctx, cancel := context.WithDeadline(context.Background(), deadline)
defer cancel()

result := make(chan string, 1)
go func() {
    time.Sleep(1 * time.Second) // Work takes far longer than we allow.
    result <- "report ready"
}()

select {
case data := <-result:
    fmt.Println("got:", data)
case <-ctx.Done():                 // Fires the moment `deadline` passes.
    fmt.Println("missed the deadline:", ctx.Err())
}

Run

How does a deadline differ from a timeout?

Both end the context; a timeout counts a duration forward from now, while a deadline names an exact instant on the clock.

In short

Deadline = a stop moment; timeout = a stop duration. Both close Done(). Next: read Done() and Err() to learn why work stopped.
