Programs and output

This folder shows the smallest complete Go program, and then the three ways to print. After this you can open any Go file, find where it starts, and read what it prints.

What this folder is for

Every other folder in this repo has the same shape as the code here. So this topic is really about recognising that shape. Once you know it you can skip past it and focus on what each example is actually teaching.

JS/TS you know

// index.js runs top to bottom
console.log("Hello, World!");

Go equivalent

package main

import "fmt"

func main() {
    fmt.Println("Hello, World!")
}

Go never runs loose statements at the top of a file. A program starts in the function main, which lives in the package main (Go spec: Program execution).

The four lines to recognise

package main
Says "this directory builds into a runnable program". Library code uses other package names.
import "fmt"
Like a JS import. fmt is the standard library's formatting and printing package. If you import something and never use it, the program won't compile.
func main() { … }
The entry point. It has no arguments and no return value. When it returns, the program ends.
fmt.Println(…)
You call a package's function as package.Function. It starts with a capital letter because only capitalised names are visible outside their package (Tour: Exported names).

What to look for in each example

Run every command from the repository root, the folder that contains go.mod.

01 · Hello World

01-programs/01-hello/main.go

  • Find the three parts in this order: package, then import, then func main.
  • You'll see this exact skeleton at the top of every other example.

Run

go run ./01-programs/01-hello

Expect

Hello, World!

Try: change the text in quotes, save, and run again.

02 · Formatted output

01-programs/02-printing/main.go

  • Print writes the text and adds no newline.
  • Println puts spaces between its arguments and adds a newline at the end, much like console.log.
  • Printf fills in a template using verbs: %s for a string, %d for an integer, %.2f for a number with two decimals. It adds no newline, so you write \n yourself.

Run

go run ./01-programs/02-printing

Expect

Shopping: apples 3
apples: 3 items, 1.50 each

Try: change %.2f to %.1f. Predict the output before you run it.

Printf verbs you'll meet in later folders

%v
Prints any value in its default format. When you're unsure, use this.
%T
Prints the value's type, for example int or []string. Useful while you're learning.
%q
Prints a string with quotes around it, which makes spaces and empty strings visible.
%s · %d · %f
String, integer, floating-point number.

Full list: fmt package: Printing.

Gotchas coming from JS/TS

  • Strings take double quotes "…" or backticks. Single quotes 'a' mean a single character (a rune, covered in Topic 09), not a string.
  • An unused import or an unused local variable is a compile error, not just a lint warning.
  • Your editor runs gofmt, which sets indentation, braces and spacing for you. There's no style to argue about.

Check yourself

You rename func main() to func start() and run the program. What happens?

A package main must declare a function named main. Without one the build fails before anything runs.

Which call prints a b and then moves to a new line?

Println puts a space between its arguments and adds a newline. Print only adds spaces between two operands when neither is a string, so it prints ab. Printf needs an explicit \n.

In short

  1. A runnable program is package main plus func main().
  2. Use Println for quick output and Printf with verbs for formatted output. Printf needs \n.
  3. Run everything from the repo root with go run ./folder/example.
