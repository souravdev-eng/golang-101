Cancelling explicitly with WithCancel

This is the heart of the package, and it's exactly the AbortController you know from JS. WithCancel hands you a context plus a cancel function. The worker watches the context; you call cancel() to stop it.

The idea

JS/TS you know

const c = new AbortController();
doWork(c.signal);
c.abort();   // worker sees signal.aborted

Go equivalent

ctx, cancel := context.WithCancel(
    context.Background())
go worker(ctx, ...)
cancel()     // worker sees <-ctx.Done()

The worker's half is a select: it waits on whichever channel is ready first — either the next job, or ctx.Done() telling it to quit. select is the shape you'll see around cancellation everywhere.

The code that matters

func worker(ctx context.Context, jobs <-chan string, report chan<- string) {
    for {
        select {
        case <-ctx.Done():            // Closed when the caller calls cancel().
            report <- "worker: cancelled, stopping"
            return                    // The worker chooses to return. Go can't force it.
        case job := <-jobs:           // Otherwise, handle the next job.
            report <- "worker: handled " + job
        }
    }
}

ctx, cancel := context.WithCancel(context.Background())
jobs <- "restock tea"; fmt.Println(<-report)
cancel();            fmt.Println(<-report)   // No job sent now, so Done() wins.

Key point: cancel() doesn't kill the goroutine. It only closes the Done channel. The worker notices and returns on its own. Nothing stops work that never checks Done().

Run it

18-context/03-with-cancel/main.go

Run

go run ./18-context/03-with-cancel

Expect

worker: handled restock tea
worker: cancelled, stopping

Try: send a second job (jobs <- "restock milk" with its own <-report) before cancel(). Predict the new middle line.

Check yourself

What does calling cancel() actually do to the worker?

Go can't stop a goroutine from outside. cancel() closes Done(); the worker's select sees it and returns itself.

In short

You hold the cancel button; the worker watches Done() in a select. Next: let the context press that button for you after a time limit.
