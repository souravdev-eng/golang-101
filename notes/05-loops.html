Loops

Go has one loop keyword: for. This folder shows its forms, how to skip or stop a loop, and how range walks through a collection.

What this folder is for

JS has for, while, do…while, for…of and forEach. In Go, for does all of these jobs (Tour: For). Once you can tell its forms apart, you can read any Go loop.

JS/TS you know

for (let i = 1; i <= 3; i++) {}
while (n > 0) { n--; }
while (true) { break; }
fruits.forEach((f, i) => {});

Go equivalent

for i := 1; i <= 3; i++ {}
for n > 0 { n-- }
for { break }
for i, f := range fruits {}

The four forms to recognise

for init; cond; post { }
A counted loop. Like JS, but with no parentheses.
for cond { }
Only a condition. This is Go's while (Tour: For is Go's "while").
for { }
Loops forever. Something inside must break or return.
for i, v := range xs { }
Gives the index and the value of each element. Use _ for the part you don't need (Tour: Range).
break · continue
break leaves the loop. continue skips to the next turn. Both act on the innermost loop only.

What to look for in each example

Run every command from the repository root.

01 · Three forms of for

05-loops/01-for-forms/main.go

  • Three loops in a row: counted, condition-only, and infinite with an exit.
  • In the counted loop, step := 1 runs once, step <= 3 is checked before each turn, and step++ runs after each turn.
  • The last loop has no condition. if attempt == 2 { break } ends it.

Run

go run ./05-loops/01-for-forms

Expect

step: 1
step: 2
step: 3
remaining: 2
remaining: 1
attempt: 1
attempt: 2

Try: make the counted loop stop at 4.

02 · Break and continue

05-loops/02-break-continue/main.go

  • When number is 2, continue skips the print. The loop goes on.
  • When number is 5, break ends the loop. 5 and 6 never print.

Run

go run ./05-loops/02-break-continue

Expect

number: 1
number: 3
number: 4

Try: change the break condition to number == 6.

03 · Nested loops

05-loops/03-nested/main.go

  • The inner loop (seats) runs all the way through for each turn of the outer loop (rows).
  • 2 rows × 3 seats = 6 lines.
  • The final comment: a break in the inner loop only leaves the inner loop.

Run

go run ./05-loops/03-nested

Expect

row 1 seat 1
row 1 seat 2
row 1 seat 3
row 2 seat 1
row 2 seat 2
row 2 seat 3

Try: use two seats per row and predict the four lines.

04 · Range over a collection

05-loops/04-range/main.go

  • []string{…} is a slice, which is Go's everyday list. Topic 07 covers it properly.
  • range gives two values: the index (starting at 0) and the element.
  • The second loop uses _ to ignore the index. Declaring index without using it would be a compile error.

Run

go run ./05-loops/04-range

Expect

0 apple
1 banana
2 pear
packed: apple
packed: banana
packed: pear

Try: add "orange" to the slice and run again.

Gotchas coming from JS/TS

  • There is no while keyword. Write for cond { }.
  • range gives the index first, then the value. for fruit := range fruits gives you the indexes, not the fruits.
  • To leave an outer loop from inside an inner one, Go uses a label: break outer (Go spec: Break statements).
  • Since Go 1.22, which this repo uses, each turn of a loop gets its own copy of the loop variable, and you can write for i := range 3 (Go 1.22 release notes). Older tutorials may say otherwise.

Check yourself

In for i, v := range []string{"a", "b"}, what is i on the first turn?

range gives the index first, and indexes start at 0. v is "a".

A loop counts 1 to 5. It calls continue at 3. What prints?

continue skips only the rest of that turn. The loop carries on with 4 and 5.

In short

  1. for is Go's only loop. It can be counted, condition-only, or infinite.
  2. range gives index then value. Use _ to ignore one of them.
  3. break and continue affect the innermost loop only.
