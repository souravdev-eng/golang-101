Operators

This folder shows how to calculate with numbers and build true-or-false expressions. Most of it will feel like JS. The value is in spotting the few places where Go is stricter.

What this folder is for

Operators are the glue inside every condition and loop you'll read next. The symbols mostly match JS. The big difference is that Go checks types, so there is no === versus == problem.

JS/TS you know

7 / 2          // 3.5
18 === 18      // true
"18" == 18     // true (!)
ok ? "yes" : "no"

Go equivalent

7 / 2          // 3 (both ints)
18 == 18       // true
"18" == 18     // compile error
// no ?: — use if/else

Go has no ternary ?: operator on purpose (Go FAQ).

The operators to recognise

+ - * /
Add, subtract, multiply, divide. With two ints, / drops the fraction.
%
Remainder after division. 7 % 2 is 1.
+= -= ++ --
Update shortcuts. x++ is a statement, so you can't write y := x++ (Go FAQ).
== != < <= > >=
Comparisons. They give a bool. Both sides must have matching types.
&& || !
And, or, not. They work only on bool values.

Full list: Go spec: Operators.

What to look for in each example

Run every command from the repository root.

01 · Arithmetic

03-operators/01-arithmetic/main.go

  • apples, baskets := 7, 2 declares two variables in one line.
  • Division gives 3 and remainder gives 1. Together they describe 7 ÷ 2.
  • += 3 then --: 7 + 3 − 1 = 9.

Run

go run ./03-operators/01-arithmetic

Expect

add: 9
subtract: 5
multiply: 14
divide: 3
remainder: 1
updated: 9

Try: change apples to 8 and predict the remainder.

02 · Comparisons and logic

03-operators/02-comparison-logic/main.go

  • == compares; = assigns. The comment on the first print line points this out.
  • Each comparison prints true or false.
  • && needs both sides true. || needs at least one. ! flips.

Run

go run ./03-operators/02-comparison-logic

Expect

equal: true
different: false
less: false at most: true
greater: false at least: true
can enter: true
has access: true
needs ticket: false

Try: set hasTicket to false and predict the last three lines.

Gotchas coming from JS/TS

  • No truthy or falsy values. !count or name && … won't compile unless the value is a bool.
  • No ?:. Write a short if/else instead.
  • x++ can't be used inside another expression.
  • Comparing an int with a float64 is a compile error. Convert one side first.

Check yourself

What does 10 % 4 give?

10 ÷ 4 is 2 with 2 left over. % returns the part left over.

count := 3. Which line compiles in Go?

A condition must be a bool. count is an int, so you compare it to get a bool.

In short

  1. The symbols match JS, but both sides must have the same type.
  2. / on ints drops the fraction. % gives the remainder.
  3. Logic operators work only on bool. There's no truthiness and no ?:.
