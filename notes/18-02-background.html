The empty root context

context.Background() is the plain, empty context every tree grows from. It is never cancelled and carries nothing. You create it once, at the top, and build every other context out of it.

The idea

Think of Background() as an open signal that never closes. Two methods tell you its state, and they're the same two methods every context has:

ctx.Done()
A channel that closes when the context is cancelled. For Background() it is nil and never closes — so you never wait on it directly.
ctx.Err()
Says why the context finished. Background() never finishes, so this is always nil.

You rarely use Background() alone. Its job is to be the parent you pass to WithCancel, WithTimeout, and friends in the next notes. There's also context.TODO() — identical, but it signals "I haven't decided which context belongs here yet".

The code that matters

ctx := context.Background()

// Done() is nil here, so we only COMPARE it — we never receive from it.
// Receiving from a nil channel (<-ch) would block forever.
fmt.Println("Done channel is nil:", ctx.Done() == nil)   // true
fmt.Println("Err is nil:", ctx.Err() == nil)             // true

Check yourself

Why does Background's Done() channel never fire?

Done() closes only when a context is cancelled or times out. Background() can do neither, so its channel stays open forever (it's nil).

In short

Background is the never-cancelled root. Next you give a context the power to stop — on your command.
