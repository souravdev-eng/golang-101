Course map

This repo has 17 topic folders, and each one holds a few tiny runnable programs. Every folder has a short note like this one. Read the note first so you know what the code is trying to show you, and then open the code.

How to use a note

  1. Read the note (7–10 min). It says what the folder is for, how it maps to JS/TS, and what to watch for in each example.
  2. Open the example's main.go. Look for the specific lines the note pointed out.
  3. Predict, then run. Guess the output first. Then run go run ./NN-topic/NN-example from the repo root and compare with the note's "Expect" block.
  4. Change one thing. Do the "Try" suggestion, predict again, and rerun.
  5. Check yourself. Answer the two questions at the end of the note without scrolling back up.

Order matters here. Each topic only uses ideas from the topics before it, so take them in sequence.
