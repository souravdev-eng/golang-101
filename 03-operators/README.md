# Operators

Calculate values and form true-or-false expressions.

Prerequisite: 02-values

Read and run in this order (about 5–10 minutes per example):

- [Arithmetic](01-arithmetic/main.go)
- [Comparisons and logic](02-comparison-logic/main.go)

## Arithmetic

Try the five common arithmetic operators.

From the repository root:

```sh
go run ./03-operators/01-arithmetic
```

Expected output:

```text
add: 9
subtract: 5
multiply: 14
divide: 3
remainder: 1
updated: 9
```

Try: Change apples to 8 and predict the remainder.

## Comparisons and logic

Comparison and logical expressions produce booleans.

From the repository root:

```sh
go run ./03-operators/02-comparison-logic
```

Expected output:

```text
equal: true
different: false
less: false at most: true
greater: false at least: true
can enter: true
has access: true
needs ticket: false
```

Try: Set hasTicket to false and predict the last three lines.
