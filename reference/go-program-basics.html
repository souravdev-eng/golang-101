CodePurpose
package mainNames the executable package.
import "fmt"Makes the fmt package available in this file.
func main() { … }Declares the command's entry function.
fmt.Println(…)Prints values, separating arguments with spaces and ending with a newline.

Glossary

Package
A group of Go source files in one directory, sharing a package name.
Import
A declaration making another package available to a source file.
Entry function
The main function in package main, called after initialization.
Standard library
Packages supplied with Go, including fmt.

Definitions grounded in the official tutorial and language specification.
